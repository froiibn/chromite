# 첫 사용자 배포 판(26.1.0) 이후 로드맵

## 목적

첫 사용자 배포 판(26.1.0, 2026-11-12 버전 체계 변경 전에는 "1.0.0")을 낸 뒤에 넣을 기능을 미리 정해 둔다. 2026-11-08 사용자와 논의해 합의했다("이 로드맵 사항은 1.0.0 이후 진행할 것으로 기록해둔다").
지금 진행 중인 로드맵(SWT 기능 이식과 [swt-parity-audit.md](swt-parity-audit.md)의 남은 빈자리)을 마친 뒤의 일이며, 첫 사용자 배포 판 전에는 사용자가 따로 정하지 않는 한 시작하지 않는다.

## 기준

사이트의 약속 "누구나 편하고 안전하게 다루는 데이터베이스 도구"를 기능으로 보여 준다.
대상은 DBA만이 아니라 시스템·애플리케이션 운영자까지이고, 핵심은 운영 데이터를 고칠 때(DML) 실수하지 않게 하는 것이다.

## 기능 목록

### 안전

| # | 기능 | 내용 |
|---|---|---|
| 1 | 영향 행 수 미리 보기 | UPDATE·DELETE를 실행하기 전에 바뀔 행 수와 대상 행 일부를 먼저 보여 주고 확인받는다 |
| 2 | 되돌리기 스크립트 자동 생성 | 실행 직전에 바뀔 행의 원래 값을 로컬에 저장하고, 되돌리는 UPDATE·INSERT 스크립트를 만든다. 커밋 뒤에도 복구할 길을 남긴다 |
| 3 | 운영 DB 보호 모드 | 운영 연결의 쓰기는 연결 이름을 직접 입력해 확인, 시간대 제한, 읽기 전용 기본값(연결 유형 설정의 확장) |
| 4 | 작업 기록 내보내기 | 누가·언제·어떤 연결에서·어떤 DML을 실행했는지 남기고 내보낸다(운영 감사 대응) |

### 편의

| # | 기능 | 내용 |
|---|---|---|
| 5 | 쿼리 라이브러리 입력 폼 | 매개 변수를 목록 선택·날짜 고르기·필수 표시가 있는 폼으로 받는다. SQL을 몰라도 저장된 쿼리를 쓴다 |
| 6 | 데이터 비교·동기화 | 두 테이블·DB의 행 차이와 동기화 스크립트(스키마 비교의 다음 단계) |
| 7 | 시각적 쿼리 작성기 | 테이블을 끌어다 JOIN·조건을 만들고 SQL을 같이 보여 준다 |
| 8 | 결과 보고서 내보내기 | 서식 있는 엑셀·PDF, 정해진 쿼리를 정해진 시간에 파일로 저장 |
| 17 | 쿼리 라이브러리 Git 강화 | 앱 안에서 저장소 clone·새로 만들기, 자동 fetch와 받지 않은 커밋 표시, 충돌을 화면에서 합치기(양쪽 비교), 브랜치 전환. 지금은 기존 작업 사본을 루트로 쓰고 Pull·Commit & Push만 하며, 시스템 git을 쓰고 자격 증명은 저장하지 않는다([swing-query-library.md](swing-query-library.md) "Git 루트") |

### Chromite Agent

| # | 기능 | 내용 |
|---|---|---|
| 9 | 자연어로 안전한 데이터 수정 | 요청을 SQL + 영향 행 미리 보기 + 되돌리기 스크립트로 묶어 제안(1·2번 위에) |
| 10 | 성능 진단 리포트 | 느린 쿼리, 인덱스 제안, 잠금 현황을 한 번에 점검 |

### 관리

| # | 기능 | 내용 |
|---|---|---|
| 11 | 알림 | 오래 열린 트랜잭션, 차단 체인, 디스크·세션 임계치 |
| 12 | 범용 작업 예약 | 백업·스크립트·내보내기를 정해진 시간에 실행. **2026-11-12 앞당겨 구현**([task-scheduling.md](task-scheduling.md), 앱 변경 #104): 모든 저장된 작업 형식, Chromite가 실행 중일 때만. 남은 것: OS 스케줄러(Chromite가 꺼져 있어도 실행, 2026-11-06 기각), 활성 프로젝트 밖의 작업, 실행 기록 여러 개 보기 |
| 13 | 감사 표 남은 항목 | 실행 중 세션의 격리 수준 바꾸기, PostgreSQL·MySQL 실제 실행 계획(두 번 실행하지 않는 설계), 다른 도구에서 연결 가져오기 나머지 |

### 조직 배포

| # | 기능 | 내용 |
|---|---|---|
| 14 | 회사용 정책 배포 | 연결 템플릿, 쓰기 금지, Agent 허용 범위를 정책 파일로 나눠 주고 사용자는 바꾸지 못하게 잠금 |
| 15 | 폐쇄망 업데이트 묶음 | 인터넷 없이 파일 하나로 업데이트 |
| 16 | Linux 판 | 지금은 Windows와 macOS만 |

## 순서

권장 순서: **1 → 2 → 5 → 3 → 14**, 그다음 1·2번 위에 9번.
1·2·5는 "편하고 안전하게"를 그대로 기능으로 보여 주고, 3·14는 회사 안에 퍼뜨릴 때 필요하다. 세부 일정은 첫 사용자 배포 판 뒤에 다시 정한다.

## 변경 이력

- 2026-11-08 처음 작성. 사용자와 1.0.0 이후 기능 16개와 권장 순서를 합의.
- 2026-11-08 편의 17번 "쿼리 라이브러리 Git 강화" 추가(사용자: Git 관련 사항은 1.0.0 이후 로드맵으로 기록). 1.0.0 전에는 구현하지 않는다.
- 2026-11-12 12번 범용 작업 예약을 앞당겨 구현(앱 변경 #104, `chromite/task-scheduling`). 표에 한 것과 남은 것.
- 2026-11-12 버전 체계 변경(앱 변경 #63, `chromite/release-26-0-5`): "1.0.0"을 첫 사용자 배포 판(26.1.0)으로. 사용자의 말을 옮긴 따옴표 안과 지난 이력의 "1.0.0"은 26.1.0을 뜻하며 그대로 둠. 파일 이름은 그대로.
