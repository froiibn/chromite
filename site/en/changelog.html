Changelog

Versions are numbered year.sequence.fix (major.minor.dev up to 0.1.4). The app's update notice links to each version's anchor (for example #v26.0.5).

26.0.7

Fixes PostgreSQL losing the uncommitted changes of other query windows when the connection was refreshed. If you use PostgreSQL, please update. The Chromite Agent input box is new, and names can be dragged from Object Explorer into a query.

  • Safety (important) · PostgreSQL: refreshing a connection (Refresh in Object Explorer, or the automatic refresh after statements such as CREATE DATABASE or DROP DATABASE) closed and reopened every session of that connection, so the uncommitted changes of other query windows were rolled back without a question and their search_path, temporary tables and manual-commit mode were lost. The reopened sessions stayed on the server after disconnecting. A refresh now reads the server again without closing a session
  • New · Drag a name: dragging a table, view, procedure or column from Object Explorer into a query window inserts its name where you drop it. Several objects, or a table's Columns folder (once it has been expanded), are inserted separated by commas. On SQL Server the name is schema.name when the window is in that database, and includes the database otherwise
  • Chromite Agent · input box and model selection: the input is one rounded box. The model is chosen with the button inside the box (only the current provider's models), the provider in the list below it. Setting up a provider for the first time moves an empty conversation to it, so the "set up a provider" notice no longer stays after the setup
  • Chromite Agent · connections that share one session ("single connection"): a call that would have to switch the database or schema is not run and says why (before, it was silently ignored or changed the query windows' schema)
  • SQL Server: a DDL statement written as schema.name, such as CREATE TABLE dbo.t, re-read the whole connection; it now re-reads that schema only (the new table shows in Object Explorer at once). The query window's database picker no longer loses the current database after the connection was re-read
  • Screens: notes no longer break in the middle of a Korean word; lines break at spaces only (connection and settings export and import, shell command approval, the backup and restore task dialogs, the data transfer wizards and others)

26.0.6

The release right after 26.0.5. It fixes SQL Server tables of the default database not showing right after connecting, tidies up annoyances found in use, and adds scheduled tasks and window compare.

  • Fix (important): right after connecting to SQL Server, the tables of the connection's default database did not show in Object Explorer until a refresh, and saved tasks that use those tables failed (introduced in 26.0.5)
  • Safety: when the script of a SQL script task opens a transaction and does not end it, Chromite asks before and after the run whether to commit, roll back or keep it open (before, nothing was asked and it stayed open)
  • Exit and setup: fixed cases where the process stayed after the window was closed. Exiting without internet access no longer waits for the update check, the error window of a second start shows in the task bar, and the setup says where to look when it still finds Chromite running
  • New · Compare: the Compare button of the query editor tool bar (also in the Query menu) lets you pick two open windows and shows them side by side: differing lines and words, previous and next difference, ignore whitespace, case and blank lines. Meant for two versions of a query or a procedure. The schema compare shows definitions in the same view
  • New · Scheduled tasks: in Database Tasks, give a saved task (backup, restore, script, export, import, table copy) a schedule and it runs by itself at those times. It runs only while Chromite is running, and a scheduled run asks nothing (if something has to be decided it fails and the task log says why)
  • Fix: canceling the "file already exists" question of an export to a file deleted the existing file
  • Query editor: the running query is marked in yellow-green (the caret line too), and releasing Alt after a column selection, scrolling or clicking with Alt held no longer jumps to the menu
  • Screens: the mouse wheel over inner lists and fields scrolls the page in Options and the connection dialog, menu item spacing in compact mode, menu separators in a visible colour (they were invisible in the dark theme) and group separators in the View and Tools menus, icon button tooltips show the function's name, the Object Explorer filter box says "Find"

26.0.5

Result and connection safety fixed and the query window and screens refined from feedback at work. From this version the numbering is year.sequence.fix, so 26.0.5 comes after 0.1.4. Updates work as before.

  • Safety: after a connection refresh (Object Explorer refresh, CREATE or DROP DATABASE), a SQL Server batch of several statements showed only its first result, dropped the results and errors of later statements and ended as "successful"; fixed
  • Safety: when SQL run by Chromite Agent fails in the middle, the Agent now reports the earlier results, the error and the statements that ran after it (before, only the error, so changes already made went unnoticed)
  • Safety: on SQL Server the read-only tools of Chromite Agent took a text such as a SELECT followed by DELETE and COMMIT without semicolons for one SELECT and ran it without asking; fixed. A text is refused unless it is proven to only read, and several statements are confirmed by their most dangerous one.
  • Safety: on connections that use a single session (SQL Server with Entra ID interactive sign-in, Snowflake, ClickHouse, BigQuery and others) the tools of Chromite Agent that measure a statement and roll it back (the actual plan of a statement that changes data) really ran it; they now refuse and say why. On the same connections the commit and rollback tools no longer report success when they ended nothing.
  • Safety: when the connection to the server is lost during a run, Chromite no longer runs a statement that changes data, a batch of several statements or a procedure call again by itself; it stops and says what is certain and what is in doubt (before, it reconnected and ran the whole text again, which could insert rows twice). The same holds for data transfer and for saving grid edits and table designs. A single SELECT that only reads is still run again, and the Messages tab says so.
  • Safety: opening the Database list in the connection dialog before saving SSH, proxy or SSL settings no longer reconnects to the server in an endless loop
  • Query window: a Change Connection button at the left of the tool bar instead of the server picker, the database picker follows the session after USE (databases created by other sessions too), a spinner and the running statement highlighted, column selection with Alt+drag, Reopen Closed Tab (Ctrl+Shift+T), a right-click menu on document tabs
  • Connections: pick the database from the server's list in the connection dialog, URL-based connections no longer show their server as localhost, idle connections are no longer closed by default
  • Results and plans: a two-level result area (Grid, Text, Messages, Server Output and plan tabs, result tabs at the bottom), the actual plan that did not appear on Oracle and SQL Server, the actual plan toggle off from the start where the database has none, the second implicit result of Oracle shown
  • Oracle and Altibase: Oracle script commands (SET SERVEROUTPUT, PROMPT, EXEC, SPOOL, a lone /), and Altibase no longer cuts a statement at a division's /
  • Chromite Agent: vLLM and Google Gemini providers, tool sets per provider with a tool finder, clearer guidance on which tool to use, Oracle PL/SQL blocks and SQL Server MERGE no longer fail when the Agent runs them, the script tool sends a SQL Server GO batch as one unit
  • Screens: the operating system's UI font one step larger, sharper text at 100% scale and more contrast in both themes, the theme follows the operating system by default, no focus border on content areas and thinner dialog title bars, a redesigned Options dialog, widening a right tool window keeps the left column's width, the macOS window as one piece
  • Fixes: the start of the data type hidden in the table designer, Korean text in message dialogs broken in the middle of words, the MySQL driver download question coming back after Cancel
  • Windows: the program is now Chromite.exe. A Chromite pinned to the taskbar still opens in this version but not from the next one: start Chromite and pin it again from its taskbar button.
  • macOS: the app in the update is Chromite.app. If the Dock item still points at the old name (ChromiteSwing), remove it and keep the new Chromite in the Dock. 0.1.3 and earlier cannot update automatically: install from the disk image.

0.1.4

Screens and behaviour refined from hands-on feedback, with fixes to transaction and data safety, installation and updates.

  • Transactions: an open transaction is shown only when the database really holds something (asked from the database), transactions opened with BEGIN TRAN in auto-commit are shown too, an unknown state is shown as unverified, and a read-only transaction can be ended in one click or automatically (setting, off by default)
  • Results: one tab per result set (Result1, Result2, …), a mid-script error keeps the earlier results and stops, results no longer stay behind when switching tabs, clicking a header selects the column (sort and filter by their icons), no selection highlight on row numbers
  • Screens: query window status in the main status bar painted in the connection colour, connection and database pickers first in the SQL Editor tool bar, Chromite Agent button at the right end, Query Library and Chromite Agent on the right on first start, a startup splash, hover afterimage in trees at 150% scaling fixed
  • Chromite Agent: provider and model in one picker under the input, conversation history, tools that read and edit open query windows (never run or save; edits are confirmed first), token usage shown
  • Options: a larger window with a settings search above the page list, Chromite Agent settings opened directly
  • Query Library: a Save button in the editor, database and schema lists of the target connection
  • Safety: a cancelled or failed data transfer closes its load connection and reports what was undone, skipping a failed row no longer loses earlier rows and Retry no longer drops rows, SSH host keys are checked behind jump servers too
  • Table designer: renaming saved columns, keys and tables, a partly failed save shows what was applied and reloads, DEFAULT names are kept
  • Install and update: Windows installs for all users (Program Files) by default with "only for me" as an option, an installation progress window after the app closes, the macOS app is named Chromite, disk image window layout
  • macOS: menus in the screen menu bar, Command (⌘) shortcuts

0.1.3

More object editing and result grid tools, and stronger execution and transaction safety.

  • Safety: re-reading a result from a multi-statement run no longer runs the whole batch again (only the SELECT that produced it is re-read); errors inside a SQL Server batch are no longer lost and reported as success
  • Transactions: switch auto/manual commit from the Query menu and the SQL Editor toolbar (asks first when a transaction is open); SQL script tasks no longer commit or roll back without asking
  • Objects: New object from Explorer folders, New Database dialogs, sequence, trigger and package templates, Oracle index, foreign key and CHECK design, property editing in the Properties view
  • Result grid: follow foreign keys with references and aggregates panels, virtual keys, hide and move columns, find in results, text view, generate SQL from rows, saved and recent filters, virtual calculated columns, referenced-value picker, array, hstore, hex and external editors, UUID
  • Execution plans: the Actual Plan toggle now also works for Oracle and Altibase (only when turned on; the statement runs once)
  • Query Manager window: every executed statement, filtered by connection, type and text
  • Query windows are saved automatically and restored after a restart (without connecting or running anything); recent scripts per connection
  • Connections: shell commands, jump servers, network profiles, change password, per-connection restrictions and connection lock
  • Data transfer: save and edit as tasks, SQL script tasks, advanced Copy Tables and Export options (emptying or re-creating tables asks first)
  • Backup: choose schemas and tables, pg_dumpall (global objects and whole cluster), tool account and extra arguments
  • Settings export, import and undo
  • Privileges: PostgreSQL column and default privileges, MySQL resource limits, Altibase replication status and commands
  • Chromite Agent: fixed every request failing on Claude models and a slow Stop; the transaction answer is now in the audit log
  • Security: passwords quoted as passwords, statements with passwords kept out of the query log, password properties masked, the hard-coded password for new Exasol users removed
  • Fixed: Oracle sequence changes (ORA-04007), SQL Server filters on queries sorted by unselected columns (1033), SQL Server parameter types, Altibase and CUBRID server output settings applied at once

0.1.2

Fixes the app not starting on macOS, and adds compare, search and editing tools.

  • macOS: fixed the app hanging at startup without a window (the 0.1.0 and 0.1.1 macOS builds). The app menu is named Chromite, and Cmd+Q asks about unsaved work and open transactions
  • Transactions: sleep and wake-up no longer roll back open transactions without asking; failed reconnects are no longer reported as success; exit asks about running jobs; smart commit; previous transactions in the log
  • Schema compare with migration script generation, and data search across a schema's tables
  • Result grid: Save and Commit, duplicate rows, multi-cell paste, copy as JSON/XML/INSERT, boolean, ENUM and date editors, LOB load from and save to file, chart and spatial views. A header sort replaces the query's ORDER BY, and column aliases show in the headers
  • SQL editor: code folding, outline, object docs on hover, Ctrl+click to find objects, text tools, pinned results and results layout, SQL terminal
  • Routines: Execute Procedure dialog, Oracle and Altibase compile with error lines, SQL Server execution trace
  • Object Explorer: object filters and quick filter, link with editor, paging for long folders, object details (dependencies), duplicate connection, default database and schema
  • Scripts and Database Tasks windows; run scripts with the native client (psql, mysql, sqlplus)
  • Connections: import from other database tools' connection files and CSV, provider properties, SSL and authentication fields, connection description, disconnect several at once, approval for H2 init SQL and SQLite extensions
  • Settings: per-connection settings, data formats, errors and timeouts, metadata, drivers, proxy and Maven repositories, logs and the other remaining settings pages
  • Drivers: a local jar you add takes precedence; the Driver Manager edits Maven entries, local clients and global libraries. Oracle RAC lock views and Cancel Query (18c and later)
  • Chromite Agent: PostgreSQL and MySQL backup and restore tools and more tools, smaller requests
  • Query Library: one parameter dialog; filter, sort and next page also work on results run with parameters
  • Compact mode (View menu); confirmations that run or change something default to Cancel
  • Fixed: the Oracle plan tool hanging on a long leading comment, changing SQL Server columns that have a default constraint, the password showing on the sqlplus command line

0.1.1

Transaction safety, and more tools for administration and development.

  • Transactions: open-transaction indicator and idle reminder, Commit and Roll Back commands with a transaction log, an open transactions list, and a separate session per query window. Disconnect, exit and error recovery never commit or roll back without asking
  • Confirmations before running: DELETE and UPDATE without WHERE, DROP, TRUNCATE, an SQL preview before saving grid edits, and approval of saved shell commands
  • Procedure debugger (PostgreSQL, Oracle)
  • Chromite Agent: database tools, per-connection and per-tool permission policy, local MCP server
  • Shared Query Library: shared folder and Git roots, export and import, save conflict checks
  • Object Explorer: delete and rename with a DDL preview, copy names, multi-select, Generate SQL
  • Settings pages: query execution, connection types, result formats, Oracle
  • Saved passwords are kept in the operating system's secure storage (Windows DPAPI, macOS Keychain); passphrase-encrypted connection export and import
  • Offline driver install bundles for closed networks, built-in SQLite driver. The MySQL driver is no longer built in: it is downloaded on first connect or installed from an offline bundle
  • Oracle DBMS_OUTPUT and Altibase output shown, login prompt for connections without a saved password, Windows certificate store, the @export command, procedure completion after CALL and EXEC
  • Copy Tables creates the primary key and maps more types; fixed shifted values for NULL columns in row-by-row inserts
  • Remaining untranslated Korean labels translated

0.1.0

The first version of Chromite.

  • Object Explorer, SQL editor with result grid, table designer, ER diagrams, data import and export, backup and restore, activity monitor
  • Built-in JDBC drivers for PostgreSQL, SQL Server, MariaDB, MySQL and Oracle
  • Built-in Java runtime (JetBrains Runtime 25)
  • Korean and English user interface, light and dark themes
  • Installer for Windows x64, disk image for Macs with Apple silicon
