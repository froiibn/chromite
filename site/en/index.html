Chromite

Database Workbench

A desktop app to connect to, query and manage PostgreSQL, SQL Server, MariaDB and MySQL, Oracle and other databases in one window. It comes with its own Java runtime, so there is nothing else to install.

Signatures and checksums

The Windows installer is code-signed by the publisher Seizia, and the macOS app is notarized by Apple. You can compare the SHA-256 of a downloaded file with the value above (Windows: Get-FileHash file, macOS: shasum -a 256 file).

Automatic updates

Chromite downloads a new version on its own and installs it when you restart the app. A downloaded file runs only after its size, SHA-256 and signature have been checked. What the update check sends is described under Privacy.
