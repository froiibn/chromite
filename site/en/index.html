PostgreSQL, SQL Server, MariaDB, MySQL and Oracle in one window

Chromite is a database workbench for Windows and macOS. Connect to a server, run SQL, edit results right in the grid, and manage tables and servers. It installs with its own Java runtime and JDBC drivers, so there is nothing else to set up.

What is included

Databases
PostgreSQL, SQL Server, MariaDB, MySQL and Oracle. Their JDBC drivers are included, except MySQL's, which is downloaded on first connect or installed from an offline bundle.
Queries
SQL editor, a result grid you can filter and edit in place, execution plans, Query Library
Objects
Object Explorer, Registered Servers, Properties, table designer, ER diagrams
Data
Import and export, backup and restore
Server admin
Activity Monitor: processes, locks, disk usage, server logs, maintenance, replication
Interface
Korean and English, light and dark themes
Runs on
Windows 10 and 11 (x64), Macs with Apple silicon

Transactions are never closed behind your back

In manual commit, changes you have not committed stay in the session. Chromite keeps that transaction in view, and you decide how it ends.

  • The query window's status line shows the open transaction, how long it has been open and how many statements it holds. Click it to commit, roll back or open the transaction log.
  • A transaction left open and unused is brought back to you as a notification after the time you set.
  • Disconnecting or closing the app asks: Commit / Roll Back / Cancel. Reconnecting after an error asks too, before the transaction is dropped.
  • UPDATE and DELETE without WHERE, DROP and TRUNCATE ask for confirmation before they run.
  • Edits in the result grid can show the SQL they will run before you save them.

A query library the team shares

Keep the checks and reports you run often in a tree and run them from there. Each query is a plain .sql file, so other tools can open it too.

  • Parameters: values are asked for when the query runs. Numbers, dates and choice lists, with defaults.
  • Schedules: while Chromite is running, a query runs at an interval or a time you set and notifies you when its condition is met.
  • Thresholds: warning and critical limits on result columns.
  • Sharing: add a network folder or a Git working copy as a library root. The tree shows the branch and the commits not pushed yet, and you pull or commit and push from the app.
  • Export and import: move a set of queries as one file.

Chromite Agent

A database agent: ask it something and it picks tools to gather evidence from the connected database, then answers. The tools target SQL Server, PostgreSQL, MariaDB and Oracle; which tools work depends on the database.

  • Slow query tuning Reads the estimated and actual plan as structured data, compares plans before and after an index, and looks at table statistics, index usage, missing and unused indexes and fragmentation. It proposes an index and can create it after you confirm.
  • Blocking and deadlocks Builds the blocking chain from the head blocker, lists locks and sessions with long open or idle transactions, and reads recent deadlock graphs. Ending a session always asks you first.
  • Health check Sessions, wait statistics, top CPU and I/O queries, database and file space, backup and job history, the server error log, and settings that differ from their defaults.
  • Procedure review Reads the source with line numbers, its dependencies and per-statement execution statistics.
More it can do
  • Schema and data Searches objects, describes tables, keys and permissions, generates DDL, samples rows and profiles columns, and compares query results. Exports to CSV, XLSX or JSON, imports CSV and copies tables.
  • Monitoring with the Query Library Runs saved checks and judges them against their thresholds.
  • Hands off to you Opens the SQL it wrote in a new query window without running it.

Safety: every tool has a policy per connection (run / confirm / blocked), and writes are blocked on production connections by default. Commit and rollback always ask. Read-only diagnostics run read-only (in a read-only transaction where the database has one), and every call goes to the audit log.

Access: the same tools are offered to external agents through a local MCP server that only this PC can reach. Providers are Claude, OpenAI and local models through Ollama; API keys are kept in the operating system's secure storage.

Works on networks without internet

One installer connects to the main databases right away, with no driver download.

  • The SQL Server, Oracle, PostgreSQL, MariaDB and SQLite drivers are in the installer. MySQL is downloaded on first connect or installed from an offline bundle.
  • For other drivers, make an offline bundle file in the Driver Manager on a PC with internet and install that file on the closed-network PC. Every file's SHA-256 is checked before it is installed.
  • With offline mode on, Chromite does not try to download driver files.
  • The automatic update check can be turned off in Options.

Step through procedures

Run PostgreSQL (PL/pgSQL) and Oracle (PL/SQL) functions and procedures in a debugger.

  • Click the margin to set a breakpoint, then follow the code with Step Over and Step Into. Oracle also has Step Out.
  • See variables, the call stack, server messages and results. While stopped, you can change a variable's value.
  • When the debugger ends with a transaction not committed in its session, it asks: Commit / Roll Back / Cancel.

PostgreSQL needs the pldebugger extension on the server, and Oracle needs debug privileges. SQL Server is not supported.

Administer four databases from one tool

SQL Server, Oracle, PostgreSQL and MariaDB in the same Activity Monitor, with the same menus.

  • Sessions and locks: the blocking chain from the head blocker and the locks of each session; end a session.
  • Job schedulers: SQL Server Agent, Oracle DBMS_SCHEDULER, PostgreSQL pg_cron and MariaDB events.
  • Disk usage, server logs (errors, warnings, slow queries), maintenance with a preview and a confirmation, and replication status.

Altibase connects too, with tables coloured by storage type, server output, and sessions and locks.

Passwords stay on your PC

Saved connection passwords and API keys are never written to workspace files.

  • They are encrypted in the operating system's secure storage: DPAPI tied to your Windows account, or the Keychain on macOS.
  • To move to a new PC, export your connections to a file encrypted with a passphrase you choose (12 characters or more) and import it there.
  • No usage statistics are collected or sent. The only requests that leave the PC are the update check, downloads of drivers that are not bundled, and calls to a Chromite Agent provider you set up. See Privacy for the details.

Signatures and checksums

The Windows installer is code-signed by the publisher Seizia, and the macOS app is notarized by Apple. You can compare the SHA-256 of a downloaded file with the value above (Windows: Get-FileHash file, macOS: shasum -a 256 file).

Automatic updates

Chromite downloads a new version on its own and installs it when you restart the app. A downloaded file runs only after its size, SHA-256 and signature have been checked. What the update check sends is described under Privacy.
