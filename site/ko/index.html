Chromite
다운로드 변경 내역 개인정보 GitHub English

PostgreSQL, SQL Server, MariaDB, MySQL, Oracle을 한 창에서 다룹니다

Chromite는 Windows와 macOS용 데이터베이스 워크벤치입니다. 서버에 연결해 SQL을 실행하고, 결과를 표에서 바로 고치고, 테이블과 서버를 관리합니다. Java 런타임과 JDBC 드라이버가 함께 설치되어 따로 준비할 것이 없습니다.

들어 있는 것

데이터베이스
PostgreSQL, SQL Server, MariaDB, MySQL, Oracle. 각 JDBC 드라이버가 함께 들어 있습니다.
쿼리
SQL 편집기, 필터와 바로 편집이 되는 결과 표, 실행 계획, 쿼리 라이브러리
개체
개체 탐색기, 등록된 서버, 속성 창, 테이블 디자이너, ER 다이어그램
데이터
가져오기와 내보내기, 백업과 복원
서버 관리
작업 모니터: 프로세스, 잠금, 공간 사용량, 서버 로그, 유지 관리, 복제
화면
한국어와 영어, 밝은 테마와 어두운 테마
지원 환경
Windows 10·11 (x64), Apple Silicon Mac

최신 파일의 버전과 내려받기 단추는 JavaScript로 채웁니다. JavaScript 없이 받으려면 releases.json에서 파일 이름(크기, SHA-256 포함)을 보고 /downloads/파일 이름을 여세요. GitHub 릴리스에도 같은 파일이 있습니다.

서명과 확인

Windows 설치 파일은 게시자 Seizia로 코드 서명되어 있고, macOS 앱은 Apple의 공증을 받았습니다. 받은 파일의 SHA-256을 위 값과 비교해 확인할 수 있습니다(Windows: Get-FileHash 파일, macOS: shasum -a 256 파일).

자동 업데이트

Chromite는 새 버전이 나오면 스스로 받아 두었다가, 앱을 다시 시작할 때 설치합니다. 받은 파일은 크기, SHA-256, 서명을 확인한 뒤에만 실행합니다. 업데이트 확인이 보내는 정보는 개인정보에 적었습니다.
