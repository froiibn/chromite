누구나 편하고 안전하게 다루는 데이터베이스 도구

시스템·애플리케이션 운영자도 조회부터 데이터 수정까지 쉽고 실수 없이

무료로 다운로드

Windows와 macOS용. 회사에서도 개인도, 모든 기능 무료.

편하게

  • 자주 쓰는 쿼리는 쿼리 라이브러리에 저장하고, 값만 넣어 바로 실행
  • 팀과 공유 폴더나 Git으로 쿼리를 함께 씀

안전하게

  • WHERE 없는 UPDATE·DELETE, DROP, TRUNCATE는 실행 전에 확인
  • 결과 표 편집은 저장 전에 실행할 SQL을 미리 볼 수 있음
  • 열린 트랜잭션을 표시하고, 묻지 않고 커밋하지 않음, 자동 롤백은 켠 경우에만

안전한 트랜잭션 관리

  • 상태 줄에 열린 트랜잭션, 열린 뒤 지난 시간, 문장 수가 보입니다. 누르면 커밋, 롤백, 트랜잭션 로그를 고릅니다.
  • 열어 둔 채 쓰지 않는 트랜잭션은 정한 시간이 지나면 알림으로 다시 묻거나 자동 롤백 처리합니다.
  • 연결을 끊거나 앱을 끝낼 때, 오류 뒤 다시 연결할 때도 커밋 / 롤백 / 취소를 묻습니다.
  • WHERE 없는 UPDATE·DELETE, DROP, TRUNCATE는 실행하기 전에 확인하고, 결과 표에서 고친 값은 저장하기 전에 실행할 SQL을 미리 봅니다.

팀이 함께 쓰는 쿼리 라이브러리

  • 네트워크 폴더나 Git 작업 사본을 라이브러리 루트로 더합니다. 트리에 브랜치와 올리지 않은 커밋 수가 보이고, Pull과 Commit & Push를 앱에서 합니다.
  • 쿼리 하나가 평범한 .sql 파일 하나라서 다른 도구에서도 열립니다.
  • 매개 변수는 실행할 때 묻고(숫자, 날짜, 선택 목록, 기본값), 결과 열의 경고·위험 기준값으로 판정합니다.
  • Chromite가 켜져 있는 동안 정한 간격이나 시각에 실행하고, 조건에 맞으면 알립니다. 쿼리 묶음은 파일 하나로 내보내고 가져옵니다.

Chromite Agent

평소 말로 물으면, 실제 데이터베이스를 확인하고 근거를 들어 답합니다.

지원 범위 자세히

  • 느린 쿼리, 끝나지 않는 UPDATE, 서버 상태를 물으면 실행 계획, 잠금과 차단 체인, 세션·대기·공간을 직접 읽고 원인과 할 일을 알려 줍니다. 어느 데이터베이스에서나 스키마·데이터·쿼리를 다루고, 시스템 정보를 직접 조회해 잠금·실행 계획·서버 상태를 진단합니다.
  • 인덱스 만들기나 세션 끝내기처럼 무언가를 바꾸는 일은 실행할 SQL을 보여 주고 확인을 받은 뒤에 하고, 운영 연결에서는 쓰기를 막습니다(기본 설정).
  • 모든 도구 호출은 감사 기록에 남습니다.
  • 제공자는 Claude, OpenAI(직접 넣은 API 키), Ollama입니다. 로컬 MCP 서버를 켜면 이 PC의 다른 AI 도구도 같은 도구를 씁니다.

기업용 폐쇄망을 위한 편의성

설치 파일 하나로 주요 데이터베이스에 바로 연결합니다. 폐쇄망에서도 드라이버를 따로 받을 필요가 없습니다.

지원 범위 자세히

  • 자주 쓰는 드라이버는 설치 파일에 미리 들어 있고, 다른 드라이버는 처음 연결할 때 받거나 오프라인 묶음으로 설치합니다.
  • 그 밖의 드라이버는 인터넷이 되는 PC의 드라이버 관리자에서 오프라인 묶음 파일 하나로 만들어 폐쇄망 PC로 옮깁니다.
  • 오프라인 모드를 켜면 드라이버 파일을 내려받으려 하지 않습니다. 자동 업데이트 확인은 옵션에서 끌 수 있습니다.

프로시저 디버깅 지원

지원 범위 자세히

  • 함수와 프로시저를 디버거에서 실행합니다.
  • 여백을 눌러 중단점을 놓고, 프로시저 단위 실행과 한 단계씩 코드 실행으로 디버깅합니다. 데이터베이스가 지원하면 프로시저 나가기도 씁니다.
  • 변수, 호출 스택, 서버 메시지, 결과를 봅니다. 멈춘 동안 변수 값을 고칠 수 있습니다.
  • 디버거를 끝낼 때 그 세션에 커밋하지 않은 트랜잭션이 있으면 커밋 / 롤백 / 취소를 묻습니다.

DBA 도구가 처음부터 들어 있습니다.

작업 모니터에서 세션과 잠금, 작업 스케줄러, 공간과 로그, 유지 관리, 복제 상태를 한곳에서 다룹니다.

지원 범위 자세히

  • 세션과 잠금: 맨 앞 블로커부터 차단 체인과 세션별 잠금을 보고, 세션을 끝냅니다.
  • 작업 스케줄러: 데이터베이스의 작업 스케줄러에 등록된 작업을 보고, 만들고, 고칩니다.
  • 공간 사용량, 서버 로그(오류·경고·느린 쿼리), 미리 보기와 확인을 거치는 유지 관리, 복제 상태.

비밀번호는 내 컴퓨터에 안전하게 보관됩니다

저장한 연결 비밀번호와 API 키는 작업 공간 파일에 남기지 않습니다.

  • 운영체제 보안 저장소에 암호화해 보관합니다. Windows는 Windows 계정에 묶인 DPAPI, macOS는 키체인을 씁니다.
  • 새 PC로 옮길 때는 직접 정한 암호(12자 이상)로 암호화한 연결 파일을 내보내고 가져옵니다.
  • 사용 통계는 모으지도 보내지도 않습니다. 밖으로 나가는 요청은 업데이트 확인, 내장되지 않은 드라이버 내려받기, 직접 설정한 Chromite Agent 제공자 호출입니다. 자세한 내용은 개인정보에 있습니다.

Windows와 macOS용 Chromite 받기

Chromite는 Windows와 macOS용 데이터베이스 워크벤치입니다. 서버에 연결해 SQL을 실행하고, 결과를 표에서 바로 고치고, 테이블과 서버를 관리합니다. Java 런타임과 JDBC 드라이버가 함께 설치되어 따로 준비할 것이 없습니다.
