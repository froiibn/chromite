PostgreSQL, SQL Server, MariaDB, MySQL, Oracle을 한 창에서 다룹니다

Chromite는 Windows와 macOS용 데이터베이스 워크벤치입니다. 서버에 연결해 SQL을 실행하고, 결과를 표에서 바로 고치고, 테이블과 서버를 관리합니다. Java 런타임과 JDBC 드라이버가 함께 설치되어 따로 준비할 것이 없습니다.

트랜잭션을 몰래 끝내지 않습니다

수동 커밋으로 일하면 커밋하지 않은 변경이 세션에 남습니다. Chromite는 그 트랜잭션을 늘 보여 주고, 끝낼지는 사용자가 정합니다.

  • 쿼리 창 상태 줄에 열린 트랜잭션, 열린 뒤 지난 시간, 문장 수가 보입니다. 누르면 커밋, 롤백, 트랜잭션 로그를 고릅니다.
  • 열어 둔 채 쓰지 않는 트랜잭션은 정한 시간이 지나면 알림으로 다시 묻습니다.
  • 연결을 끊거나 앱을 끝낼 때 커밋 / 롤백 / 취소를 묻습니다. 오류 뒤 다시 연결할 때도 트랜잭션을 버리기 전에 묻습니다.
  • WHERE 없는 UPDATE·DELETE, DROP, TRUNCATE는 실행하기 전에 확인합니다.
  • 결과 표에서 고친 값은 저장하기 전에 실행할 SQL을 미리 보고 확인할 수 있습니다.

팀이 함께 쓰는 쿼리 라이브러리

자주 쓰는 점검·보고 쿼리를 트리에 모아 두고 바로 실행합니다. 쿼리 하나가 평범한 .sql 파일 하나라서 다른 도구에서도 열립니다.

  • 매개 변수: 실행할 때 값을 묻습니다. 숫자, 날짜, 선택 목록과 기본값을 정할 수 있습니다.
  • 일정: Chromite가 켜져 있는 동안 정한 간격이나 시각에 실행하고, 조건에 맞으면 알립니다.
  • 기준값: 결과 열에 경고·위험 기준을 두고 판정합니다.
  • 공유: 네트워크 폴더나 Git 작업 사본을 라이브러리 루트로 더합니다. 트리에 브랜치와 올리지 않은 커밋 수가 보이고, Pull과 Commit & Push를 앱에서 합니다.
  • 내보내기·가져오기: 쿼리 묶음을 파일 하나로 옮깁니다.

Chromite Agent

물어보면 연결한 데이터베이스에서 도구를 골라 근거를 모으고 답하는 데이터베이스 에이전트입니다. 도구는 SQL Server, PostgreSQL, MariaDB, Oracle 기준이며 DB마다 쓸 수 있는 도구가 다릅니다.

  • 느린 쿼리 튜닝 예상·실제 실행 계획을 구조화된 데이터로 읽고, 인덱스 전후 계획을 비교하고, 테이블 통계, 인덱스 사용, 누락·미사용 인덱스, 조각화를 봅니다. 인덱스를 제안하고, 확인을 받은 뒤 만들 수 있습니다.
  • 블로킹과 교착 상태 맨 앞 블로커부터 차단 체인을 만들고, 잠금과 오래 열리거나 쉬고 있는 트랜잭션의 세션을 나열하고, 최근 교착 상태 그래프를 읽습니다. 세션 종료는 늘 확인을 받습니다.
  • 상태 점검 세션, 대기 통계, CPU·I/O 상위 쿼리, 데이터베이스·파일 공간, 백업·작업 기록, 서버 오류 로그, 기본값과 다른 설정을 봅니다.
  • 프로시저 검토 줄 번호가 붙은 원본, 의존 관계, 문장별 실행 통계를 읽습니다.
그 밖에 할 수 있는 일
  • 스키마와 데이터 개체를 찾고, 테이블·키·권한을 설명하고, DDL을 만들고, 행 표본과 열 프로파일을 보고, 쿼리 결과를 비교합니다. CSV·XLSX·JSON으로 내보내고, CSV를 가져오고, 테이블을 복사합니다.
  • 쿼리 라이브러리로 감시 저장한 점검 쿼리를 실행하고 기준값으로 판정합니다.
  • 사용자에게 넘기기 만든 SQL을 실행하지 않고 새 쿼리 창에 엽니다.

안전: 모든 도구에 연결별 정책(자동 실행 / 확인 / 막음)이 있고, 운영 연결의 쓰기는 기본으로 막힙니다. 커밋과 롤백은 늘 확인을 받습니다. 읽기 진단은 읽기 전용으로 실행하고(지원하는 DB는 읽기 전용 트랜잭션), 모든 호출은 감사 기록에 남습니다.

연결: 같은 도구를 이 PC 안에서만 접속되는 로컬 MCP 서버로 외부 에이전트에도 제공합니다. 제공자는 Claude, OpenAI, Ollama(로컬 모델)이고, API 키는 운영체제 보안 저장소에 둡니다.

인터넷이 없는 망에서도 씁니다

설치 파일 하나로 주요 데이터베이스에 바로 연결합니다. 드라이버를 내려받을 인터넷이 없어도 됩니다.

  • SQL Server, Oracle, PostgreSQL, MariaDB, MySQL, SQLite 드라이버가 설치 파일에 들어 있습니다.
  • 그 밖의 드라이버는 인터넷이 되는 PC의 드라이버 관리자에서 오프라인 묶음 파일 하나로 만들고, 폐쇄망 PC에서 그 파일을 설치합니다. 설치 전에 모든 파일의 SHA-256을 확인합니다.
  • 오프라인 모드를 켜면 드라이버 파일을 내려받으려 하지 않습니다.
  • 자동 업데이트 확인은 옵션에서 끌 수 있습니다.

프로시저를 한 줄씩 따라갑니다

PostgreSQL(PL/pgSQL)과 Oracle(PL/SQL)의 함수와 프로시저를 디버거에서 실행합니다.

  • 여백을 눌러 중단점을 놓고, 프로시저 단위 실행과 한 단계씩 코드 실행으로 따라갑니다. Oracle에서는 프로시저 나가기도 됩니다.
  • 변수, 호출 스택, 서버 메시지, 결과를 봅니다. 멈춘 동안 변수 값을 고칠 수 있습니다.
  • 디버거를 끝낼 때 그 세션에 커밋하지 않은 트랜잭션이 있으면 커밋 / 롤백 / 취소를 묻습니다.

PostgreSQL 서버에는 pldebugger 확장이 필요하고, Oracle은 디버그 권한이 필요합니다. SQL Server는 지원하지 않습니다.

네 가지 데이터베이스를 한 도구에서 관리합니다

SQL Server, Oracle, PostgreSQL, MariaDB를 같은 작업 모니터와 같은 메뉴로 다룹니다.

  • 세션과 잠금: 맨 앞 블로커부터 차단 체인과 세션별 잠금을 보고, 세션을 끝냅니다.
  • 작업 스케줄러: SQL Server 에이전트, Oracle DBMS_SCHEDULER, PostgreSQL pg_cron, MariaDB 이벤트.
  • 공간 사용량, 서버 로그(오류·경고·느린 쿼리), 미리 보기와 확인을 거치는 유지 관리, 복제 상태.

Altibase도 연결합니다. 저장 방식별 테이블 색, 서버 출력, 세션과 잠금을 지원합니다.

비밀번호는 이 PC에만 둡니다

저장한 연결 비밀번호와 API 키는 작업 공간 파일에 남기지 않습니다.

  • 운영체제 보안 저장소에 암호화해 둡니다. Windows는 Windows 계정에 묶인 DPAPI, macOS는 키체인을 씁니다.
  • 새 PC로 옮길 때는 직접 정한 암호(12자 이상)로 암호화한 연결 파일을 내보내고 가져옵니다.
  • 사용 통계는 모으지도 보내지도 않습니다. 밖으로 나가는 요청은 업데이트 확인, 내장되지 않은 드라이버 내려받기, 직접 설정한 Chromite Agent 제공자 호출입니다. 자세한 내용은 개인정보에 있습니다.

서명과 확인

Windows 설치 파일은 게시자 Seizia로 코드 서명되어 있고, macOS 앱은 Apple의 공증을 받았습니다. 받은 파일의 SHA-256을 위 값과 비교해 확인할 수 있습니다(Windows: Get-FileHash 파일, macOS: shasum -a 256 파일).

자동 업데이트

Chromite는 새 버전이 나오면 스스로 받아 두었다가, 앱을 다시 시작할 때 설치합니다. 받은 파일은 크기, SHA-256, 서명을 확인한 뒤에만 실행합니다. 업데이트 확인이 보내는 정보는 개인정보에 적었습니다.
