기능과 지원 범위

Chromite는 JDBC 드라이버가 있는 데이터베이스라면 어디에나 연결해 쿼리를 실행하고 결과를 다룹니다. 아래 표는 그 밖의 기능을 데이터베이스마다 어디까지 지원하는지 보여 줍니다. Chromite 0.1.3의 코드와 설계 문서로 확인한 내용만 적었습니다.

표 읽는 법

  • 지원: 그 데이터베이스에서 기능을 씁니다. 작은 글씨는 조건입니다.
  • 일부: 기능의 일부만 됩니다. 빠진 부분과 이유를 적었습니다.
  • 미지원: 쓸 수 없습니다. 이유는 두 가지로 나눕니다. “DB가 제공하지 않음”은 데이터베이스에 그 기능이나 API가 없는 경우이고, “Chromite에서 아직 지원하지 않음”은 Chromite에 그 데이터베이스용 구현이 없는 경우입니다. 뒤의 것은 데이터베이스에 그 기능이 있는지와는 상관없습니다.
  • 확인 필요: 같은 코드를 물려받아 메뉴는 켜지지만 그 데이터베이스에서 확인하지 않은 경우입니다.

찾는 데이터베이스가 없습니다.

열 설명

쿼리 편집기·결과
SQL 편집기, 결과 표, 개체 탐색기. JDBC로 연결되는 모든 데이터베이스에서 씁니다. 표에 없는 데이터베이스도 드라이버 관리자에서 JDBC 드라이버를 더해 연결합니다.
프로시저 디버거
중단점, 프로시저 단위 실행, 한 단계씩 코드 실행, 프로시저 나가기, 변수와 호출 스택, 멈춘 동안 변수 값 고치기.
실행 추적
SQL Server 저장 프로시저를 한 번 실행하며 문장마다 줄, 시간, CPU, 행 수, 읽기·쓰기를 기록합니다(확장 이벤트). 프로시저 디버거가 없는 SQL Server를 위한 대안입니다.
실제 실행 계획
쿼리 창의 토글을 켜면 문장을 한 번만 실행하면서 실제 계획을 받습니다.
예상 실행 계획
실행하지 않고 계획만 봅니다. 드라이버가 계획 기능을 제공하면 같은 보기로 보입니다.
세션·잠금
작업 모니터의 프로세스와 잠금: 맨 앞 블로커부터 차단 체인, 세션별 잠금, 세션 끝내기.
작업 스케줄러
데이터베이스의 작업 스케줄러(SQL Server 에이전트, DBMS_SCHEDULER, pg_cron, 이벤트)에 등록된 작업을 보고 만들고 고칩니다.
공간·로그
작업 모니터의 공간 사용량과 서버 로그(오류, 경고, 느린 쿼리).
유지 관리
인덱스 다시 만들기, 통계 갱신, VACUUM 같은 작업을 미리 보기와 확인을 거쳐 실행합니다.
복제 상태
복제와 가용성 구성의 상태를 읽기 전용으로 봅니다.
보안 편집기
로그인·사용자·역할과 권한을 고칩니다.
네이티브 백업·복원
데이터베이스의 백업 도구(SQL Server BACKUP·RESTORE, pg_dump·pg_restore, mysqldump)로 백업하고 복원합니다. pg_dump와 mysqldump는 이 PC에 설치되어 있어야 합니다.
스키마 비교
개체 탐색기의 정보로 두 데이터베이스의 테이블·열·인덱스·외래 키를 비교하고 변경 스크립트를 만듭니다. 모든 데이터베이스에서 같은 방식입니다. 종류가 다른 데이터베이스끼리는 뷰·루틴·트리거·시퀀스는 있는지만 비교합니다. UNIQUE·CHECK 제약 조건, 주석, 권한은 비교하지 않습니다.
Chromite Agent 공통 도구
스키마·데이터·쿼리 도구와, 모델이 쓴 진단 SQL을 읽기 전용으로 실행하는 도구. 어느 데이터베이스에서나 시스템 정보를 직접 조회해 진단합니다. 읽기로 확인되지 않는 문장은 실행하지 않습니다.
Agent 전용 진단 도구
실행 계획, 잠금과 차단 체인, 세션·대기·공간을 미리 만든 진단 쿼리로 읽는 도구. 이 도구가 없는 데이터베이스는 공통 도구로 진단합니다.
드라이버
미리 설치: 설치 파일에 들어 있음. 처음 연결할 때 받음: 인터넷이 되면 처음 연결할 때 받음. 직접 지정: 드라이버 관리자에서 JAR 파일을 지정.
오프라인 묶음
인터넷이 되는 PC의 드라이버 관리자에서 드라이버를 파일 하나로 묶어 폐쇄망 PC에 설치합니다. 미리 설치된 드라이버는 묶을 필요가 없습니다.

데이터베이스별 기능

  • SQL Server: SQL Server 에이전트의 작업, 단계, 일정, 경고, 운영자, 오류 로그, 작업 활동 모니터. Express에는 에이전트가 없습니다.
  • Altibase: 저장 방식별 테이블 색, 서버 출력, 세션과 잠금, 실제 실행 계획, 복제 상태와 명령.
