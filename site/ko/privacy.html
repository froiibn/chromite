개인정보

앱의 업데이트 확인

업데이트 확인이 켜져 있으면 Chromite는 이 사이트의 릴리스 목록(https://chromite.seizia.com/downloads/releases.json)을 읽고, 새 버전이 있으면 그 설치 파일을 같은 곳에서 받습니다.

  • 요청에는 모든 Chromite가 똑같이 쓰는 고정된 User-Agent 하나만 들어갑니다. 설치 ID, 계정, 사용 기록, 연결한 데이터베이스 정보, 쿠키는 보내지 않습니다.
  • 인터넷 연결이 없거나 회사 네트워크가 막으면 조용히 건너뜁니다.
  • 옵션에서 자동 업데이트 확인을 끌 수 있습니다.

Chromite Agent

Chromite Agent는 직접 설정하기 전에는 아무것도 보내지 않습니다. 옵션의 Chromite Agent 탭에서 제공자(Anthropic Claude, OpenAI 또는 OpenAI 호환 주소, Ollama)를 고르고 자신의 API 키나 Ollama 주소를 넣어야 쓸 수 있습니다. 요청은 이 PC에서 고른 제공자의 주소로 바로 갑니다. 이 사이트나 다른 Chromite 서버를 거치지 않고, Chromite는 그 내용을 모으지 않습니다.

  • 보내는 것: 대화에 쓴 글과 그때까지의 대화 전체, 현재 연결의 이름·드라이버와 데이터베이스 이름, Chromite Agent가 실행한 도구의 결과. 도구 결과에는 테이블·열 같은 구조 정보, 쿼리 문장과 실행 결과(한 번에 기본 100행, 최대 10,000행), 실행 계획, 세션·잠금·서버 설정 같은 서버 상태가 들어갈 수 있습니다. 연결의 비밀번호와 인증 정보는 도구 결과에 넣지 않습니다.
  • 기본 설정에서 읽기 도구는 묻지 않고 실행됩니다. 데이터나 구조를 바꾸는 도구는 실행 전에 확인을 묻고, 운영(Production) 연결에서는 그 연결에 직접 허용하기 전까지 막힙니다.
  • Ollama를 쓰면 요청은 입력한 Ollama 서버(대개 이 PC나 사내 네트워크)로만 갑니다.
  • 제공자에게 간 내용은 그 제공자의 개인정보 처리방침과 약관을 따릅니다.
  • 0.1.0 다음 버전부터 API 키는 이 PC 운영체제의 보안 저장소에 암호화되어 저장되고(Windows는 Windows 계정에 묶이고, macOS는 키체인을 씁니다) 설정 파일에는 쓰지 않으며, 설정 화면에는 다시 보이지 않습니다. 0.1.0은 키를 Chromite 작업 공간 설정 파일에 암호화하지 않은 채로 저장했습니다. 새 버전은 그런 키를 처음 쓸 때 보안 저장소로 옮기고 암호화하지 않은 사본을 지웁니다. 대화 기록과 도구 실행 기록은 작업 공간에 남습니다.

로컬 MCP 서버는 기본으로 꺼져 있습니다. 켜면 이 PC 안(127.0.0.1)에서 온, 설정 화면의 토큰을 가진 요청만 받습니다. 이 서버에 연결한 다른 AI 도구에도 같은 권한·확인 규칙이 적용되며, 그 도구가 결과를 어디로 보내는지는 그 도구의 설정과 약관을 따릅니다.

저장된 비밀번호

  • 저장한 연결 비밀번호와 그 밖의 자격 증명(SSH·프록시 비밀번호, 네트워크 프로필, Maven 저장소)은 이 PC를 떠나지 않고 운영체제의 보안 저장소에 암호화되어 저장됩니다(Windows는 Windows 계정에 묶이고, macOS는 키체인을 씁니다). 어디로도 보내지 않고 작업 공간 파일에도 남기지 않습니다.
  • 이전 버전은 이것들을 작업 공간에, 모든 설치에서 같은 키로 암호화한 파일이나 암호화하지 않은 설정 파일로 두었습니다. 새 버전은 시작할 때 보안 저장소로 옮기고, 옮긴 사본을 확인한 뒤 그 파일과 설정을 지웁니다.
  • 그래서 작업 공간을 다른 PC로 복사해도 비밀번호는 따라가지 않습니다. 비밀번호까지 옮기려면 파일 > 연결 내보내기에서 직접 정한 암호로 내보내세요.

이 사이트

  • 쿠키, 분석 도구, 광고, 외부 글꼴이나 스크립트를 쓰지 않습니다. 모든 파일은 이 사이트에서만 받습니다.
  • 서버는 모든 HTTP 요청처럼 접속 기록(IP 주소, 시각, 요청한 주소, User-Agent, 응답 코드)을 남기며, 30일이 지나면 지웁니다. 이 기록은 서버 운영과 오용 대응에만 씁니다.
