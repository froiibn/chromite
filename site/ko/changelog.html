다운로드 지원 범위 변경 내역 개인정보 GitHub English

변경 내역

버전 번호는 연도.차례.수정 형식입니다(0.1.4까지는 주.부.개발). 각 버전의 앵커(예: #v26.0.5)는 앱의 업데이트 알림에서 링크합니다.

26.0.6

26.0.5 바로 다음의 수정판입니다. SQL Server에서 연결한 직후 기본 데이터베이스의 테이블이 보이지 않던 문제를 고치고, 써 보며 나온 불편을 정리했습니다.

  • 수정(중요): SQL Server에 연결한 직후, 연결의 기본 데이터베이스에서 개체 탐색기의 테이블이 새로 고치기 전까지 보이지 않고 그 테이블을 쓰는 저장된 작업이 실패하던 문제(26.0.5에서 생긴 문제입니다)
  • 안전: SQL 스크립트 작업의 스크립트가 트랜잭션을 열고 끝내지 않으면 실행 전과 후에 커밋·롤백·열어 두기를 묻습니다(전에는 묻지 않고 열린 채 남았습니다)
  • 종료와 설치: 창을 닫은 뒤에도 프로세스가 남던 경우를 고쳤습니다. 인터넷이 없는 환경에서 끝낼 때 업데이트 확인을 기다리지 않고, Chromite를 한 번 더 띄웠을 때의 오류 창이 작업 표시줄에 보이며, 설치 프로그램이 "실행 중" 안내에서 어디를 봐야 하는지 알려 줍니다
  • 쿼리 편집기: 실행 중인 쿼리 영역을 연두색으로 표시(커서가 있는 줄도), Alt를 누른 채 세로 선택·스크롤·클릭을 한 뒤 Alt를 놓아도 메뉴로 넘어가지 않음
  • 화면: 옵션과 연결 대화상자에서 안쪽 목록·입력란 위의 마우스 휠이 화면을 스크롤, 촘촘한 모드의 메뉴 항목 여백, 메뉴 구분선을 보이는 색으로(어두운 테마에서는 보이지 않았습니다)와 보기·도구 메뉴의 묶음 구분선, 아이콘 단추의 도구 설명을 기능 이름으로, 개체 탐색기 검색 칸 문구를 "찾기"로

26.0.5

회사에서 써 본 의견으로 결과와 연결의 안전을 고치고, 쿼리 창과 화면을 다듬은 버전입니다. 이 버전부터 버전 번호가 연도.차례.수정으로 바뀌어 0.1.4 다음이 26.0.5입니다. 업데이트는 전과 같이 됩니다.

  • 안전: 연결을 새로 고친 뒤(개체 탐색기의 새로 고침, CREATE·DROP DATABASE 실행 뒤) SQL Server에서 여러 문장을 한 번에 실행하면 첫 결과만 보이고 뒤 문장의 결과와 오류가 빠진 채 "성공"으로 끝나던 문제 수정
  • 안전: Chromite Agent가 실행한 SQL이 중간에 실패해도 앞의 결과, 오류, 오류 뒤에 실행된 문장까지 모두 알림(전에는 오류만 알려 이미 실행된 변경을 놓쳤습니다)
  • 안전: Chromite Agent의 읽기 전용 도구가 SQL Server에서 세미콜론 없이 SELECT 뒤에 붙은 DELETE·COMMIT 같은 문장을 SELECT 하나로 보고 확인 없이 실행하던 문제 수정. 읽기라고 증명되지 않으면 거절하고, 여러 문장은 가장 위험한 문장을 기준으로 확인을 받습니다.
  • 안전: 세션 하나만 쓰는 연결(SQL Server의 Entra ID 대화형 로그인, Snowflake, ClickHouse, BigQuery 등)에서 Chromite Agent가 "실행한 뒤 롤백"으로 재는 도구(데이터를 바꾸는 문장의 실제 실행 계획 등)가 그 문장을 실제로 실행하던 문제 수정(이제 거절하고 이유를 알림). 같은 연결에서 커밋·롤백 도구가 아무것도 끝내지 않고 성공을 알리던 문제도 수정
  • 안전: 실행 중에 서버 연결이 끊기면 데이터를 바꾸는 문장, 여러 문장, 프로시저 호출을 스스로 다시 실행하지 않고 멈춘 뒤 무엇이 확실하고 무엇이 불확실한지 알림(전에는 다시 연결한 뒤 통째로 다시 실행해 INSERT가 두 번 들어갈 수 있었습니다). 데이터 전송, 결과 표 저장, 표 디자이너 저장도 같습니다. 읽기만 하는 SELECT 하나는 전처럼 다시 실행하고 메시지에 그 사실을 적습니다.
  • 안전: 연결 대화상자에서 SSH·프록시·SSL 설정을 저장하기 전에 데이터베이스 목록을 펼치면 서버에 끝없이 다시 연결하던 문제 수정
  • 쿼리 창: 도구 막대의 서버 선택 대신 맨 왼쪽에 [연결 변경] 단추, USE 뒤 데이터베이스 선택이 세션을 따라감(다른 세션이 만든 데이터베이스 포함), 실행 중 회전 표시와 실행 중인 문장 강조, Alt+끌기로 세로(열) 선택, 닫은 탭 다시 열기(Ctrl+Shift+T), 문서 탭의 오른쪽 클릭 메뉴
  • 연결: 연결 대화상자에서 서버의 데이터베이스 목록으로 고르기, URL로 만든 연결의 서버 이름이 localhost로 보이던 문제 수정, 쉬고 있는 연결을 기본으로 끊지 않음
  • 결과와 실행 계획: 결과 영역을 두 단으로(격자·텍스트·메시지·서버 출력·실행 계획 탭, 결과 탭은 아래), Oracle·SQL Server에서 실제 실행 계획이 나오지 않던 문제 수정, 실제 계획을 지원하지 않는 DB에서는 토글을 처음부터 끔, Oracle 암시적 결과의 둘째 결과도 보임
  • Oracle·Altibase: Oracle 스크립트 명령(SET SERVEROUTPUT, PROMPT, EXEC, SPOOL, 한 줄의 /) 처리, Altibase에서 나눗셈의 /에서 문장이 잘리던 문제 수정
  • Chromite Agent: 제공자에 vLLM과 Google Gemini 추가, 제공자에 맞춘 도구 묶음과 도구 찾기, 도구를 고르는 설명 다듬음, Oracle PL/SQL 블록과 SQL Server MERGE 실행이 늘 실패하던 문제 수정, 스크립트 실행 도구가 SQL Server의 GO 배치를 한 단위로 보냄
  • 화면: 운영체제의 UI 글꼴을 한 단계 크게, 100% 배율에서 더 선명한 글자와 두 테마의 대비, 기본 테마는 운영체제 설정을 따름, 내용 영역의 포커스 테두리와 두꺼운 대화상자 제목 줄 정리, 옵션 화면 새 디자인, 오른쪽 도구 창을 넓혀도 왼쪽 열 너비 유지, macOS 창을 한 덩어리로
  • 수정: 표 디자이너에서 데이터 형식의 앞부분이 가려지던 문제, 메시지 대화상자의 한국어가 낱말 중간에서 줄이 바뀌던 문제, MySQL 드라이버 내려받기를 취소해도 질문이 다시 뜨던 문제
  • Windows: 실행 파일 이름이 Chromite.exe로 바뀌었습니다. 작업 표시줄에 고정한 Chromite는 이 버전에서는 그대로 열리지만 다음 버전부터 열리지 않으니, Chromite를 띄운 뒤 작업 표시줄 단추에서 다시 고정하세요.
  • macOS: 업데이트로 받는 앱 이름이 Chromite.app입니다. Dock의 항목이 옛 이름(ChromiteSwing)을 가리키면 Dock에서 빼고 새 Chromite를 다시 고정하세요. 0.1.3 이하는 자동 업데이트가 되지 않으니 디스크 이미지로 설치하세요.

0.1.4

직접 써 보며 모은 의견으로 화면과 동작을 다듬고, 트랜잭션·데이터 안전과 설치·업데이트를 고친 버전입니다.

  • 트랜잭션: 열린 트랜잭션은 DB가 실제로 무언가를 쥐고 있을 때만 표시(DB에 직접 확인), 자동 커밋에서 BEGIN TRAN으로 연 트랜잭션도 표시, 확인할 수 없으면 "확인할 수 없음"으로 표시, 조회만 한 트랜잭션은 한 번에 끝내기와 자동으로 끝내기 설정(기본 꺼짐)
  • 결과: 결과 집합마다 탭(결과1, 결과2 …), 중간 오류에서는 앞 결과를 두고 멈춤, 탭을 바꿔도 이전 결과가 남던 문제 수정, 머리글을 누르면 열 선택(정렬·필터는 아이콘), 행 번호 칸의 선택 강조 제거
  • 화면: 쿼리 창 상태를 창 맨 아래 상태 표시줄로 옮기고 연결 색으로 칠함, SQL 편집기 도구 막대는 연결·DB 선택이 먼저, Chromite Agent 단추를 오른쪽 끝에, 처음 실행하면 오른쪽에 쿼리 라이브러리와 Chromite Agent, 시작 화면 표시, 트리의 마우스 잔상(150% 배율) 수정, 한국어 문구 끝 말줄임표 정리
  • Chromite Agent: 제공자와 모델을 한 곳에서 고르기(입력란 아래), 대화 기록, 열린 쿼리 창을 읽고 고치는 도구(실행·저장은 하지 않고 고치기 전에 확인), 사용한 토큰 표시
  • 옵션: 창을 넓히고 왼쪽 목록 위에 설정 찾기, Chromite Agent 설정으로 바로 열기
  • 쿼리 라이브러리: 편집 화면에 저장 단추, 대상 연결의 DB·스키마 목록
  • 안전: 데이터 전송을 취소하거나 시작에서 실패하면 적재 연결을 닫고 되돌린 내용을 알림, 실패한 행을 건너뛸 때 앞서 넣은 행이 사라지던 문제와 다시 시도에서 행이 빠지던 문제 수정, 점프 서버 뒤 SSH 호스트 키도 확인
  • 표 디자이너: 저장된 열·키·표 이름 바꾸기, 저장이 중간에 실패하면 적용된 것과 아닌 것을 보이고 다시 읽음, DEFAULT 이름 유지
  • 설치·업데이트: Windows는 기본으로 모든 사용자(Program Files)에 설치하고 "나만 설치"도 고를 수 있음, 앱이 꺼진 뒤 설치 진행 창 표시, macOS 앱 이름을 Chromite로, 디스크 이미지 창 배치
  • macOS: 메뉴를 화면 맨 위 메뉴 막대에, 단축키는 Command(⌘)

0.1.3

개체 편집과 결과 표 기능을 넓히고, 실행·트랜잭션 안전을 더 단단히 한 버전입니다.

  • 안전: 여러 문장을 한 번에 실행한 결과를 다시 읽을 때 배치 전체를 다시 실행하던 문제 수정(그 결과를 만든 SELECT만 다시 읽음), SQL Server 배치 안의 오류가 사라지고 "성공"으로 나오던 문제 수정
  • 트랜잭션: 쿼리 메뉴와 SQL 편집기 도구 막대에서 자동/수동 커밋 전환(열린 트랜잭션이 있으면 먼저 묻습니다), SQL 스크립트 작업이 묻지 않고 커밋·롤백하지 않음
  • 개체: 탐색기 폴더에서 새 개체 만들기, 새 데이터베이스 대화상자, 시퀀스·트리거·패키지 템플릿, Oracle 인덱스·외래 키·CHECK 설계, Properties 창에서 속성 편집
  • 결과 표: 외래 키 따라가기와 참조·집계 패널, 가상 키, 열 숨기기·이동, 결과 안에서 찾기, 텍스트 보기, 결과 행에서 SQL 만들기, 저장한 필터와 최근 필터, 가상(계산) 열, 참조 값 고르기·배열·hstore·16진수·외부 편집기·UUID
  • 실행 계획: 실제 실행 계획 토글을 Oracle·Altibase로 넓힘(켰을 때만, 문장은 한 번만 실행)
  • Query Manager 창: 실행된 모든 문장을 연결·종류·글자로 걸러 봄
  • 쿼리 창 자동 저장과 다시 시작할 때 복원(연결하거나 실행하지 않음), 연결별 최근 스크립트
  • 연결: 셸 명령, 점프 서버, 네트워크 프로필, 비밀번호 변경, 연결별 제한과 연결 잠금
  • 데이터 전송: 작업으로 저장·편집, SQL 스크립트 작업, Copy Tables·Export 고급 옵션(비우기·다시 만들기는 먼저 묻습니다)
  • 백업: 스키마·테이블 고르기, pg_dumpall(전역 개체·클러스터 전체), 도구 계정과 추가 인수
  • 설정 내보내기·가져오기·되돌리기
  • 권한: PostgreSQL 열 권한·기본 권한, MySQL 자원 제한, Altibase 복제 상태와 명령
  • Chromite Agent: Claude 모델에서 모든 요청이 실패하던 문제와 중지가 늦던 문제 수정, 트랜잭션 질문의 답을 감사 기록에 남김
  • 보안: 비밀번호를 비밀번호로 따옴표 처리, 비밀번호가 든 문장을 실행 기록에서 뺌, 속성 표에서 비밀번호 가림, Exasol 새 사용자의 고정 비밀번호 제거
  • 수정: Oracle 시퀀스 변경 오류(ORA-04007), SQL Server 정렬 열 필터 오류(1033), SQL Server 매개 변수 형식 표시, Altibase·CUBRID 서버 출력 설정 즉시 반영

0.1.2

macOS에서 앱이 시작되지 않던 문제를 고치고, 비교·검색·편집 도구를 더한 버전입니다.

  • macOS: 시작할 때 창이 뜨지 않고 멈추던 문제를 고쳤습니다(0.1.0·0.1.1의 macOS판). 앱 메뉴 이름이 Chromite로 나오고, Cmd+Q로 끝낼 때 저장과 열린 트랜잭션을 묻습니다
  • 트랜잭션: 잠자기 모드와 깨어날 때 열린 트랜잭션을 묻지 않고 롤백하던 문제 수정, 다시 연결 실패를 성공으로 알리던 문제 수정, 실행 중인 작업이 있으면 종료 전에 확인, 스마트 커밋, 지난 트랜잭션 기록
  • 스키마 비교와 마이그레이션 스크립트 생성, 스키마의 테이블에서 값을 찾는 데이터 검색
  • 결과 표: 저장하고 커밋, 행 복제·여러 칸 붙여넣기·JSON/XML/INSERT로 복사, 불리언·ENUM·날짜 편집기, LOB 파일 불러오기·저장, 차트와 공간 데이터 보기. 머리글 정렬이 쿼리의 ORDER BY를 대신하고, 열 별칭이 머리글에 보입니다
  • SQL 편집기: 코드 접기, 개요, 마우스를 올리면 개체 설명, Ctrl+클릭으로 개체 찾기, 텍스트 도구, 결과 고정과 배치, SQL 터미널
  • 루틴: 프로시저 실행 대화상자, Oracle·Altibase 컴파일과 오류 줄 표시, SQL Server 실행 추적
  • 개체 탐색기: 개체 필터와 빠른 필터, 편집기와 연결, 긴 폴더 나눠 읽기, 개체 상세(의존 관계), 연결 복제, 기본 데이터베이스·스키마
  • 스크립트 창과 저장된 작업 창, 네이티브 클라이언트(psql, mysql, sqlplus)로 스크립트 실행
  • 연결: 다른 데이터베이스 도구의 연결 파일과 CSV에서 가져오기, 공급자 속성·SSL·인증 입력란, 연결 설명, 한꺼번에 연결 끊기, H2 초기화 SQL·SQLite 확장 승인
  • 설정: 연결별 설정, 데이터 형식, 오류와 시간 제한, 메타데이터, 드라이버·프록시·Maven 저장소, 로그 등 남은 설정 화면
  • 드라이버: 직접 추가한 로컬 jar 우선, 드라이버 관리자에서 Maven 항목·로컬 클라이언트·전역 라이브러리 편집. Oracle RAC 잠금 보기와 쿼리 취소(18c 이상)
  • Chromite Agent: PostgreSQL·MySQL 백업·복원 도구와 더 많은 도구, 요청 크기 줄임
  • 쿼리 라이브러리: 매개변수 대화상자를 하나로, 매개변수로 실행한 결과에서도 필터·정렬·다음 페이지
  • 촘촘한 모드(보기 메뉴), 실행이나 변경을 일으키는 확인 창의 기본 단추를 취소로
  • 수정: Oracle 실행 계획 도구가 긴 머리 주석에서 멈추던 문제, SQL Server 기본값 제약이 있는 열을 바꾸지 못하던 문제, sqlplus 실행 때 비밀번호가 명령줄에 보이던 문제

트랜잭션 안전장치와 관리·개발 도구를 넓힌 버전입니다.

  • Chromite Agent: 데이터베이스 작업 도구, 연결·도구별 권한 정책, 로컬 MCP 서버
  • 쿼리 라이브러리 공유: 공유 폴더·Git 루트, 내보내기·가져오기, 저장 충돌 확인
  • 개체 탐색기: 삭제·이름 바꾸기(DDL 미리 보기), 이름 복사, 여러 개 선택, SQL 생성

  • 저장된 비밀번호를 운영체제 보안 저장소(Windows DPAPI, macOS 키체인)에 보관하고, 암호로 암호화한 연결 내보내기·가져오기를 추가
