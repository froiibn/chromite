Chromite의 첫 버전입니다.

  • 개체 탐색기, SQL 편집기와 결과 표, 테이블 디자이너, ER 다이어그램, 데이터 가져오기·내보내기, 백업·복원, 작업 모니터
  • PostgreSQL, SQL Server, MariaDB, MySQL, Oracle JDBC 드라이버 내장
  • Java 런타임(JetBrains Runtime 25) 내장
  • 한국어·영어 화면, 밝은 테마·어두운 테마
  • Windows x64 설치 프로그램, Apple Silicon Mac용 디스크 이미지
